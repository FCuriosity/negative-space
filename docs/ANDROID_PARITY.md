# 安卓 alpha5 功能对照

本次以桌面已有组件为基准接入安卓，不将“系统能显示提醒”作为完整移植的验收终点

## 已接入

| 区域 | 安卓实现 |
| --- | --- |
| 打开理由 | 系统悬浮 WebView 与应用内共用同一 Reminder，沿用桌面 ReasonTags 与 OpeningIntention，支持快捷/自定义标签、意图确认、记录后返回桌面、继续 5 分钟 |
| 自律等级 | 温和、摩擦等待 30 秒＋至少 5 字理由＋输入挑战、严格约定不提供临时放行；不承诺阻止系统关闭留白 |
| 专注空间 | 复用 FocusSpaces 和 FocusPanel，命名、配色、图片、项目、多个列表、正向/倒计时、保存/编辑/删除、一键启动 |
| 专注结束 | 自动提示心得；摩擦模式提前结束由原生引擎校验等待与挑战；严格计时不提前结束 |
| 专注背景 | 系统文件选择器，只读取用户选中的 JPG/PNG/WebP，在本地缩小后保存；不申请整库照片权限 |
| 时间表 | 复用 FocusTimetable，手机单日视图、模块手柄触摸放置、精确时间输入、按模块时长计算结束、冲突检查、跨午夜、每周重复 |
| 循环限制 | 复用桌面 Schedules，可选择列表、日期及时间段 |
| 统计 | 复用桌面 History，7/14 天、项目筛选、应用用时、专注时间、时间线 |
| 任务与习惯 | 复用桌面 Tasks、DailyTasks，保留跨日事项、编辑/删除/多选/历史及每日习惯打卡 |
| 历历在目与镜湖 | 继续复用原组件，新增镜湖人物设置 |
| 规则与设置 | 多个允许时段、按星期配额、自定义列表/项目、奖励应用与时长、记录保留期限 |
| 管理恢复 | 记住用户开启/暂停选择；关闭界面继续管理，重新打开时验证权限后恢复；暂停和备份导入保持关闭；设置分别显示已保存选择与实际服务状态 |
| 本地备份 | Android 系统文件选择器导入/导出，恢复前确认，恢复时暂停管理；活动专注期间禁止替换 |

## 平台边界

- Android 不执行桌面的进程正常退出/强制退出动作，「这次先放下」记录理由后返回系统桌面，原应用保留
- 无设备管理员或无障碍权限，不承诺防强退、强制锁机；托管审批、跨设备同步在桌面也未完整实现
- Android 浏览器扩展与其他 App 内推荐流隐藏未接入
- 统计采用前台切换与锁屏状态，不把未触摸屏幕直接判定为空闲
- 时间表仅在管理服务运行且进入开始分钟时启动，锁屏、已有专注、错过时段不会补记
- 普通未受限打开会统计次数，可在历历在目补写理由；本次系统悬浮表单用于触发规则的打开

## 安装与签名

alpha1/alpha2 未保存临时 CI 调试签名私钥，无法无损覆盖更新；alpha3 使用独立包名 `cn.liubai.app.preview3`，旧版可保留
从本次提供的本机签名安装包开始，固定签名存放在开发者本机 `.local/android-signing/`，不提交 Git，不上传私钥，后续相同包名和证书可覆盖升级
应备份此目录中的 keystore 与密码文件，丢失后无法重建原签名

GitHub Actions 的 `liubai-android-alpha5-ci` 产物仅供构建测试，使用临时 CI 证书，不等于本机固定签名版本；不要混装两者
本机重签命令使用 `scripts/sign-android-preview.sh`，通过 `LIUBAI_JAVA_HOME` 和 `LIUBAI_APKSIGNER_JAR` 指定官方工具
