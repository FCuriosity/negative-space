# 留白 0.12.1 桌面测试版

## 本次修复

修复 Windows 仅识别英文 bilibili 进程名、漏掉「哔哩哔哩.exe」的问题。连接管理区分「已安装，等待运行识别」和「运行中已识别」，显示运行进程名。正常关闭请求失败时显示实际失败状态。新增中文名称 Windows 测试进程的识别、监测、正常关闭与取消关闭回归测试。

更新时先从托盘退出旧版留白，再安装新版；不需要卸载或删除已有数据。打开哔哩哔哩后，在连接管理应看到「运行中已识别 · 哔哩哔哩.exe」。

## 下载与安装

- `macos-arm64.dmg`：Apple 芯片 Mac，macOS 13 及以上，拖入 Applications
- `macos-x64.dmg`：Intel Mac，macOS 13 及以上，拖入 Applications
- `windows-x64-setup.exe`：Windows 10/11 x64，按安装向导安装，无需另装 .NET
- `SHA256SUMS.txt`：安装包 SHA-256 校验值

## 功能

应用前台用时、切换次数、每日配额与可用时段、连续使用休息、专注计时与计划、打开理由、心得时间轴、镜湖与男女角色切换。Windows 共用已有规则引擎，并通过 Win32 采样；关闭主窗口后继续运行，使用托盘菜单退出。

Windows 默认识别微信（WeChat/Weixin）、哔哩哔哩、Steam；小红书仅在存在可识别的 xiaohongshu/rednote 原生进程时管理，网页版通过扩展管理。先提醒保存，再请求正常关闭；强制退出必须在规则中主动开启并在当次提醒中再次确认。管理员权限运行的应用可能无法管理，本程序不会自动提权。

## 浏览器连接

Chrome / Edge：在留白「连接管理」选择浏览器并准备本地连接，点击「打开扩展文件夹」，在浏览器扩展页加载该文件夹。更新后重新加载扩展。桌面 App 和网页配额分别统计。安装包内含扩展，无需下载项目源码。

## 测试与限制

发布流程要求 TypeScript 测试、两个架构的 Mac 构建和自检、Windows 原生编译和协议自检、Electron 界面/IPC/SQLite/Win32 采样冒烟测试全部通过。真实第三方应用的保存对话框、商店版/PWA 身份及各 Windows 系统版本仍需实机验收，当前作为测试版发布。

当前没有 Apple Developer ID 公证或 Windows Authenticode 发布证书，系统可能显示开发者无法验证；不应关闭系统安全保护。正式签名发行需配置对应证书。数据只保存在本机 SQLite；安装包更新不会主动删除数据，升级前可在偏好设置导出备份。

托管审批/跨设备批准尚未实现；严格模式不提供防止用户退出程序、停止后台或卸载的保证。
