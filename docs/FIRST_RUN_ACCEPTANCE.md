# 首次使用：一条规则的验收

## 产品目标

一个没有看过源码的人，不经口头指导，能从安装包开始安装留白，选择一个分心应用，设置一条温和规则，安全体验一次提醒，主动开启正式管理，并解释这条规则什么时候生效。

首轮只完成「一个应用 → 一条温和规则 → 一次安全演示」。不要求配置屏蔽列表、时间表、专注空间、镜湖或历史规则。

## 当前实现

- Mac、Windows 新安装和空浏览器预览使用独立的首次状态：没有预置启用规则，正式管理暂停
- 旧数据没有首次标记时按已有用户处理，不弹出新手流程，不覆盖旧规则
- 选择一个可管理的电脑 App，每日 1–180 分钟，默认 30 分钟
- 固定温和模式、60 秒保存宽限期、关闭强制退出；不开启次数限制、时段限制和强制休息
- 演示完全由界面状态驱动，不调用应用启动、退出、放行或真实用量模拟，不写入使用、理由、心得或镜湖记录
- 演示结束后才保存规则；可修改后再次体验，或选择「仅保存，稍后开启」
- 原生服务在尚未配置任何启用规则时拒绝开启管理，包括从其他管理入口尝试开启；跳过引导后自行配置规则的用户仍可主动开启管理
- 桌面界面只有在识别到所选应用后才可点击「开启这条规则」；浏览器预览只允许保存
- 中途关闭后保留已保存的规则，未完成时下次可继续；升级、重新打开不会重新初始化用户数据
- 已跳过引导并自行创建配置的用户不会被首次流程覆盖，继续使用自律规则与连接管理

### 生效说明必须与实际一致

开启正式管理之后才统计实际使用。所选 App 在前台且未空闲，累计达到每日分钟额度时提醒；空闲阈值和每日重置时区展示在引导里。每天零点重置额度。

当前温和模式会在提醒后留 60 秒保存，之后请求正常退出应用；可填写理由继续 5 分钟，强制退出关闭。不能把它描述成永不关闭应用的纯通知模式。关闭留白窗口继续管理，从菜单栏或托盘退出留白会停止。

## 无口头指导的首轮验收

### 准备

1. 招募 5 名未看过源码、未接触留白的体验者，覆盖 Mac 与 Windows，记录系统和安装包版本
2. 使用独立系统账户或干净测试设备，已有一个受支持的分心 App；不清理体验者原有留白数据
3. 只提供安装包、随包安装说明和下面的任务卡，不提供源码、命令行或开发者陪同讲解
4. 系统签名或信任提示若阻止安装，记录为安装阻碍，不要求参与者关闭安全保护；当前测试包未完成正式签名公证，不能据此宣称上架验收通过
5. 测试提醒使用内置安全演示，不以将真实应用配额设为零、关闭真实应用或构造真实超额记录替代

### 给体验者的任务卡

> 请安装并打开留白，选一个最容易让你分心的应用，给它设置每天 30 分钟的温和规则，体验一次提醒。看懂后决定是否开启这条规则。
>
> 完成后，请用自己的话说：这条规则什么时候会提醒你？提醒之后会发生什么？如果想暂停，你会去哪里？

### 观察步骤与可检验结果

| 步骤 | 验收结果 | 失败例子 |
| --- | --- | --- |
| 安装并打开 | 不使用终端、不查看源码，正常进入第一步 | 找不到应用入口、签名阻止运行、启动白屏 |
| 选择应用 | 知道只需选一个，并能说出选中了哪个电脑 App | 误以为这是网页拦截、误选所有应用 |
| 设置规则 | 能找到并设置每日 30 分钟，知道当前还没开启管理 | 以为填写数字立即会关闭应用 |
| 体验提醒 | 自行找到体验按钮，知道这是演示，真实应用保持原样 | 演示启动/退出其他应用、产生真实使用或镜湖记录 |
| 开启前理解 | 能说出「主动开启后、前台累计达到额度、每天零点重置」 | 以为安装后自动生效、按后台运行时间计时 |
| 理解后续 | 知道提醒有保存宽限期、可以填写理由继续、不会强杀 | 以为提醒完全不会请求正常退出 |
| 主动开启 | 只开启所选的一条温和规则，明确看到管理已开启 | 无动作自动开启、连带开启其他默认配额 |
| 暂停和恢复 | 能在连接管理暂停，知道关闭窗口与退出程序的差异 | 关窗口后误以为管理停止 |
| 再次打开 | 规则保存、状态可辨，没有重复引导和重复规则 | 规则丢失、再次生成预置限制 |

主持人只观察并记录，卡住时不要口头引导。可让参与者放弃，不代替其操作。记录首次卡住的页面、原话、时间和截图；修复后换新参与者复测。

### 首轮通过标准

- 5 人中至少 4 人在 5 分钟内独立完成安装后流程；安装耗时和阻碍单独记录
- 至少 4 人正确复述生效条件与暂停方法，不用引导性提问补答案
- 所有参与者的演示均未触发真实应用操作或写入真实活动记录
- 所有开启行为均来自用户明确点击，启用规则只有所选的一条
- 若安装需要开发者协助、出现意外退出或未经确认开启，视为阻断问题，不以总完成率抵消

## 工程验证与真人验收分开记录

自动化覆盖新装默认暂停、提前开启被拒绝、规则参数边界、只有一条规则、演示后保存仍暂停、重启与旧数据兼容、明确开启后的用量阈值和保存宽限期，并分别检查 Mac / Windows 入口。

界面检查覆盖选应用、修改时长、安全演示、仅保存、刷新后的持久化和管理状态。Windows 系统级安装与真人无指导验收需要在目标设备另行完成，测试通过不能替代这两项。
