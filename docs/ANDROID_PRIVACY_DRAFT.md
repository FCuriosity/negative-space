## 本地处理的信息

在你明确开启管理并授权之后，留白通过 Android 使用情况 API 读取前台切换事件，在本机筛选你管理的应用，保存其标识、切回次数和使用时间
为提供自律规则、专注与回顾功能，保存你主动设置的配额、时段、专注记录、心得、事项、理由标签和意图选择
设置页在本地显示设备型号、安卓及 WebView 版本、最近识别的支持应用、服务状态与暂停原因，用于用户排查提醒是否生效；不会上传这些诊断信息
仅当你主动选择专注背景图片或备份文件时读取该文件；导出备份只写入你指定的位置，不读取整个相册
不读取微信聊天、账号、通讯录、其他应用屏幕、浏览内容、录音或定位
不建立云账户，不上传这些信息，无广告或行为分析服务，没有网络权限

## 权限与目的

| 权限/系统能力 | 用途 | 不授权或撤销后 |
|---|---|---|
| 使用情况访问 | 获取切换事件，计算所选应用的时长和次数 | 无法进行真实应用使用统计和管理 |
| 在其他应用上层显示 | 规则触发时显示可操作的温和提醒 | 无法开启正式管理，可使用本地专注和事项 |
| 通知 | 显示运行状态和暂停入口 | 通知栏入口可能不可见，可在留白设置中暂停 |
| 前台服务 specialUse | 用户主动开启后保持统计与提醒 | 停止服务即暂停管理 |

不申请无障碍服务、全部应用列表、系统写入或设备管理员权限

## 保存、删除与撤回

信息存储在应用私有 SQLite 数据库，Android 云备份已关闭
使用、打开、专注与回顾记录默认保留 90 天，清理在引擎运行时执行；事项与用户配置长期保存在本机
你可暂停管理、撤销系统权限；事项可删除及恢复；系统「应用信息 → 存储 → 清除数据」或卸载留白会删除全部本地记录，操作前请自行确认
首个内测版本暂无数据导出与迁移，不承诺跨设备恢复

## 组件说明

使用 Android 系统 WebView 呈现安装包内置的 React 界面，使用 Zod 校验数据、Lucide 显示图标
这些组件在留白中不接入远程服务；WebView 仅允许访问打包资源，拒绝外部网页与网络请求
手机系统或应用商店自身的隐私规则由对应提供方说明
