## Alpha2 · OPPO 报告后的修复（2026-10-12）

确认并修复：
- 专注启动原来只创建计时会话，没有启动前台提醒服务
- 专注名单原来固定为娱乐应用，未包含微信；现在可逐项选择
- 使用事件按查询时间过滤会漏掉延迟返回的事件，改为 30 秒重查窗口、事件水位及同时间戳去重，旧于已处理事件的乱序数据不会倒退当前应用
- 引擎忙时原来返回 UI 缓存，可能导致提醒消失或服务误停；现在每次轮询等待对应引擎结果

新增设置页运行诊断、系统悬浮窗安全测试和系统应用/电池设置入口；计时与提醒状态分别展示，权限不足不会创建伪成功的专注会话

本地：182 项自动化测试通过，包含微信配额未用完时触发专注提醒、仅计时、不合法名单与保存名单回归

Android 打包与模拟器：本次工作流新增真实 JavaScript 桥调用、未授权启动拒绝、专注时微信提醒、专注结束后的每日次数规则验证，结果以对应 Actions 运行记录为准

OPPO 真机：尚待用户复测；模拟器结果不能代表 ColorOS 的后台存活策略

安装兼容：alpha1 使用临时调试签名且未保留私钥，不能保证覆盖升级；alpha2 使用独立包名 `cn.liubai.app.preview2`，名称「留白修复内测」，与旧版共存，不读取或迁移旧包的私有记录。请保留旧版数据，暂停旧版管理后测试新包。商店版必须另行配置长期发布签名，临时调试包不可视为正式发布方案
