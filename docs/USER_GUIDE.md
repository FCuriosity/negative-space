# 使用指南

本指南对应当前源码；安装包的具体功能以对应版本的发布说明为准。

## 使用桌面应用

在 [GitHub Releases](https://github.com/FCuriosity/negative-space/releases) 下载测试安装包：Apple 芯片 Mac 选 arm64，Intel Mac 选 x64，Windows 选 x64 setup.exe。构建流程只有在三平台构建与测试全部通过后才发布。安装及签名状态见 [发布说明](RELEASE.md)。

### Mac / Windows

打开安装后的「留白」，检查每日配额，再进入侧栏「连接管理」点击「开始管理这些应用」。首次默认暂停管理。

- **哔哩哔哩 App：** 默认每日 30 分钟，每连续使用 20 分钟休息 5 分钟。
- **小红书 App：** 默认每日 20 分钟，可自行修改。支持本机安装的 iPad 兼容版 rednote。
- **微信：** 默认每日最多打开 10 次。每次从其他应用切回都会增加一次；留白理由/限制提醒后的返回不会重复计数。
- 配额按星期覆盖、允许时段、专注会话和循环时间表都由本机规则引擎执行。
- 每秒获取前台应用身份和空闲状态；空闲、锁屏及休眠不计入活动时间。专注期间按选定项目归属活动。
- 达到限制先提醒，至少留出 60 秒保存工作，然后请求应用**正常退出**。应用取消退出或弹出保存对话框时，不会自动强杀。
- 温和模式填写理由后确认放行 5 分钟；摩擦模式等待 30 秒，填写至少 5 字理由，完整输入「我确认这次打开有明确目的」，放行 5 分钟。等待由原生引擎的单调时钟校验。
- 强制退出默认关闭。必须在规则中开启，正常退出仍未完成后，再在当次提醒中勾选确认。
- 关闭留白窗口后，菜单栏继续管理；**退出留白进程会停止管理**。当前没有防强退、开机启动或独立系统守护服务。

这里管理的是整个电脑应用的使用。原生 B 站/小红书内部的推荐流、课程、指定作者，尚不能分别放行或屏蔽；浏览器扩展单独负责网页精细过滤。

### 今日要事与每日事项

- 首页和「任务与习惯」共用当天清单，支持编辑名称与项目、勾选完成、多选批量完成 / 改为未完成 / 删除，以及恢复当天删除的事项
- 按设置中的时区在零点切换到新一天，昨日内容和完成状态保留；软件关闭期间跨日也无需补跑归档
- 「历历在目」新增「每日事项」，沿用按日、周、月自动收起的时间线；未完成历史事项可「续做到今天」，复制为新一天的事项，不覆盖昨日记录，重复点击不会重复创建
- 每日事项长期保存在本机并随备份导入导出，不随专注与使用记录的保留期清理；已删除事项保留删除标记，今日可恢复
- 旧版事项没有创建日期，首次加载时归入升级当天并标记「旧版事项」，保留标题与完成状态，不推测历史日期

### 正向计时与自定义背景

- 专注计时区可切换「倒计时 / 正向计时」。正向计时从 00:00 累计，点击「完成专注」后按实际秒数记录，并进入心得填写。满 1 分钟计为完成，获得一颗星，累计参与 60 分钟奖励；不足 1 分钟保存为短暂尝试，不发星光与奖励。
- 正向计时刷新和重启后继续累计，采用经过的墙钟时间（包括锁屏、休眠与关闭程序期间），不代表已验证的工作时长。它没有固定承诺终点，因此不提供严格模式。
- 「选择专注背景」可选林间、海岸、晨光、暮色配色，或导入本机 JPG / PNG / WebP 图片（单张原图最多 10 MB，最多 10 张，自动缩小压缩）；图片保存在本地数据及导出备份中，不上传。计时区和全屏专注显示柔和遮罩，保证文字可读。新建空间也可分别保存背景。
- 正向场景放入时间表时仍需要预留时长；显示向上累计，到预留时间结束时自动完成。直接从场景卡启动时，由你手动完成。

### 自定义专注空间与周时间表

- 「专注空间 → 新建空间」保存场景名称、1–720 分钟整数时长、项目、屏蔽列表、自律等级和林间/海岸/晨光/暮色氛围。一键进入后沿用原有计时、心得、星光与奖励逻辑。
- 「时间表」统一管理每周安排。左侧模块可拖入周一至周日的时间轴；落点上边缘是开始时间，结束时间 = 开始时间 + 模块时长，视觉高度与时长成比例。拖动按 5 分钟对齐，手动输入可精确到分钟。
- 支持拖动已有安排、精确调整开始时间、暂停和删除；重叠的已启用专注模块会被拒绝。跨午夜模块分段显示到次日，包括周日到下周一。
- 已安排模块保存一份独立场景配置；修改或删除原空间不会突然改变既有时间表。旧版循环限制保留在时间表下方「其他循环限制」。
- 桌面管理开启且未锁屏时，在安排开始的那一分钟自动启动专注，重复采样、重启不会重复开始。启动时已有专注、锁屏或配置失效会记录跳过原因；关闭软件错过的安排不补开、不补发成果。前端浏览器预览仅模拟计时。
- 定时专注沿用本地时区；到点实际启动后才执行对应屏蔽列表，结束后可写心得。严格专注期间不可调整时间表；保存判断与退出机制仍沿用原有自律等级。

### 允许使用时段与打开意图

- 在「自律规则 → 编辑 → 允许使用时段」添加一个或多个时段，每段可选星期、开始和结束时间，支持跨午夜；没有时段表示全天可用。
- 电脑 App 每次切回时保存当时是否处于允许时段外。时段外打开需填写理由，并主动选择「有明确目的」或「无意识打开」。理由同步保存到历历在目；无意识打开计入镜湖，有明确目的或尚未确认均不计黑洞。
- 温和模式填写后可继续 5 分钟；摩擦模式仍需等待 30 秒、至少 5 字理由及输入挑战；严格模式可以记录判断，但不能临时放行。也可以直接保存判断后正常退出应用。
- 临时放行期间再次切回仍需记录本次意图。提醒后的返回不重复计次。规则修改不改写历史判断；同一次打开同时超额和在时段外，只计一个黑洞。
- 时间窗口也用于浏览器扩展的限制；本次镜湖意图登记针对电脑 App。旧记录不会根据当前时段补记。

### 浏览器网页管理（Chrome / Edge）

桌面 App 管理和网页管理需要分别接入。「连接管理」中的「浏览器管理」显示扩展连接状态；网站卡片未连接时明确显示「扩展未连接」。

1. 在留白侧栏进入「连接管理」，展开「连接浏览器」，选择 Chrome 或 Edge，点击「准备本地连接」。此操作只写入对应浏览器的 Native Messaging 主机清单，允许本项目固定 ID 的扩展连接。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发人员模式，点击留白中的「打开扩展文件夹」，加载该目录（源码开发时是 `dist/extension`）。之前安装过旧扩展的，请重新加载。
3. 扩展更新后，在浏览器扩展页重新加载留白（当前扩展版本 0.2.1），再刷新已打开的网页。保持留白运行并开启管理。
4. 扩展弹窗与留白「连接管理」都显示已连接，才代表桌面配额已接入；能隐藏推荐流本身不代表本地连接成功。扩展每 30 秒独立发送连接心跳，切换到普通网页或留白窗口后仍保持连接；关闭浏览器、停用扩展后最多 90 秒显示断开。心跳不计入网页用时和打开次数。

知乎、小红书网页版默认每日 0 分钟、摩擦模式，打开即需要等待 30 秒、填写理由及指定句子，临时放行 5 分钟；可在网站配额卡片中修改额度和等级。网页版与独立 App 分别计时计次；每次回到网站标签计一次，重复心跳不重复计数。只有前台、非空闲、允许使用的网站时间计入用时，限制页停留不计时。严格限制不能通过输入挑战解除。

扩展只向本机发送受管理的平台域名和前台状态，不传送路径、查询词、页面正文或聊天内容。本机原生引擎负责配额、挑战验证与保存。推荐流隐藏/页面允许列表仍在扩展中配置，不能穿过桌面配额。

目前只接入 Chrome / Edge，Safari、Codex 内置浏览器、豆包浏览器和夸克尚未验证或接入。每个浏览器及独立配置文件需分别安装扩展。断开时知乎、小红书显示连接提醒。网页限制是扩展内的遮挡与交互限制，不是系统网络封锁；停用或卸载扩展后无法继续拦截。

### 每日配额液面

- 液面采用薄荷、玫瑰、蜜桃、雾蓝与薰衣草五组柔和配色，去除玻璃反光；三层波浪以不同方向和速度缓慢流动。暂停规则时波浪静止，减少动态效果偏好会关闭动画。

首页与自律规则统一显示容器液面。每张卡片同时显示「今日已用时间」「今日打开次数」，即使没有设置次数上限也不会隐藏实际次数。

- 设置时长时：液面高度 = 当天剩余秒数 / 当天总秒数；总额包含星期覆盖和当天专注奖励。时间越少，液面越低。
- 只设置次数时：显示「次数还剩」，按剩余次数绘制液面；同时设置时长和次数时，液面优先使用时长，次数独立显示。
- 没有每日上限时显示「不限」；零额度或超额时显示空容器，不出现负数或无效百分比。
- 数值按本地自然日重置，原生状态更新时实时刷新；遵守系统减少动态效果偏好。

### 镜湖

侧栏「镜湖」将真实的专注与超额打开记录化成星光、黑洞和湖中倒影。

- 完成一次专注，左罐增加一颗星；提前结束不计。按会话 ID 去重，重启或重复结算不会重复增加。
- 切回受管理 App 时，保存当时是否处于允许时段外，以及是否用完每日时长或次数（包含星期规则、专注奖励）。第 N 次额度内打开允许，第 N+1 次才超额。停用规则不参与。
- 超额或时段外打开先进入待确认列表；用户选择「无意点开」才进入右侧黑洞罐，「有意打开」不计。可修改、撤回判断，也可补写或修改「历历在目」中的打开理由。
- 亮度为 `(完成专注次数 − 已确认无意超额打开次数) × 20%`，限定 0–100%。逐渐呈现湖光、面容与倒影，净星光 5 颗时最亮。明暗只用于回顾，不影响拦截或奖励。
- 默认显示当前保留期内记录（90 天），也可看今天。旧版专注完成记录正常计星；旧打开记录没有当时的配额快照，不推断、不补记黑洞。
- 场景采用日落将尽的星空与金发围巾少年。星光越多，夜空星点越丰富、明亮，并同步倒映在水中；黑洞削弱光亮。低亮度保留背光剪影，湖光足够时显露面容。
- 「光是怎样照亮镜湖的？」可展开查看规则与独立的光影演示板块。演示说明、滑块和演示百分比放在此处，画面内不显示演示注释；画面外的真实湖面亮度始终来自真实记录。演示不写入数据，收起板块会恢复真实湖面。减少动态效果偏好会关闭动画。

### 历历在目

- 时间轴按「月 → 周 → 日」组织，今天默认展开，过去的日节点默认收起；周一到来后上一自然周收起，月初到来后上一月收起。打开页面期间跨过日期边界也会自动更新。
- 每周按周一至周日计算，使用设置中的时区；跨月周在各自月份内拆分，不重复记入。节点显示所选范围内的次数与心得数量，可逐层展开继续查看、补写和修改。折叠不删除记录，仍遵守当前历史保留时长。
- 默认查看全部保留记录；今天、近 7 天、近 30 天和 App 筛选仍可使用。当天超过 20 条记录时，可继续加载当天记录，不影响其他日期节点或总数。
- 打开受管控 App、补写理由和临时放行弹窗均提供快捷理由标签：摸鱼、回复消息、查资料、看课程、休息一下。可创建、删除并组合标签，补充自己的文字；自定义标签保存在本地并随备份保存。删除标签不会改变已有记录。
- 「无意识，但改邪归正」填入理由后，当前打开弹窗可确认「记录理由，关闭应用」，保存理由并请求正常关闭；历史补写仅保存文字。
- 快捷标签只辅助填写，不自动放行。摩擦模式仍需等待 30 秒、至少 5 字理由和输入挑战；严格模式仍不提供临时放行。


侧栏新增「历历在目」，桌面宽屏下分为两栏：

- **专注心得时间线**：专注完成或提前结束后自动邀请写心得；允许稍后补写、修改。记录结束时间、实际时长、项目和完成状态，每次专注只保存一篇心得。提前结束不算完成次数、不发奖励。
- **打开 App 的理由**：每次从其他应用切回受管理 App，记录一次打开并邀请填写理由。可稍后补写。成功挑战放行的理由也会保存，放行次数与打开次数分开统计。
- 按今天、近 7 天、近 30 天或全部保留记录筛选，理由栏还可按 App 筛选；显示专注完成次数、心得篇数、打开次数和临时放行次数。

Mac 次数来自应用切换事件并以每秒采样补充；Windows 每秒采样前台进程（小于一秒的快速往返可能漏记）；同一次访问不会因重复采样增加。后台进程启动不算用户打开。旧版已有的启动记录保留并标记，不伪造过去的切换记录或理由。管理暂停时不统计。

心得与理由与其他历史采用同一保留天数（默认 90 天），可导出备份。原生记录由专用保存命令写入，普通 UI 状态保存不会覆盖它们；旧版数据自动补齐空记录集合。

### 自定义专注时长

首页及「专注空间」保留 25 / 50 / 60 分钟快捷选择，同时增加「自定义」入口，支持 1–720 的整数分钟。非法输入不能开始计时。开始后记住上次使用的时长，重启后仍可使用；计时、完成记录及奖励按实际选择的分钟数计算，进行中的专注不能通过修改输入改变时长。

### 数据和权限

Mac 原生数据保存在 `~/Library/Application Support/留白/native.sqlite3`，Windows 保存在 `%APPDATA%/Liubai/native.sqlite3`，SQLite WAL + FULL 同步。无账户、上传或遥测，不采集窗口标题、聊天内容、页面内容。浏览器预览和 Mac 应用数据独立。UI 保存规则不能覆盖后台活动计数；当前 Mac 备份导入只合并配置/任务/会话等，使用计数和奖励保持原生数据权威。

不要求辅助功能或屏幕录制权限，不修改 hosts、防火墙、系统工具或浏览器策略。严格模式限制挑战放行并锁定活动严格专注的规则修改，但不能防止用户退出留白或直接修改本机数据。托管审批仍未接入。

侧边栏在窄窗口仍显示完整中文名称；更窄时采用图标在上、文字在下的布局。当前页面有高亮与左侧标记，悬停可查看功能说明。
