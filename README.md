# 留白：在顺手点开之前，给自己一次选择。

面向 Mac 与 Windows 的本地优先专注工具。设置使用边界，记录打开意图，把时间留给真正想做的事。

## 看一次完整使用过程

**真实录屏待补充。** 收到原始素材后，将在这里放入 30—60 秒视频，展示下面这一条完整使用路径。

[产品展示页源码](docs/product/index.html) · [本地预览与录屏接入](docs/PRODUCT_PAGE.md)

想完成一件事 → 顺手打开应用 → 收到提醒 → 写下「无意识，但改邪归正」，确认关闭 → 回到任务 → 完成专注，镜湖增加一颗星。

## 下载留白

前往 [GitHub Releases](https://github.com/FCuriosity/negative-space/releases) 下载对应安装包：

| 你的电脑 | 选择的文件 |
| --- | --- |
| Apple 芯片 Mac（M 系列） | `macos-arm64.dmg` |
| Intel Mac | `macos-x64.dmg` |
| Windows 10 / 11，x64 | `windows-x64-setup.exe` |

当前为测试版，尚未完成 Apple 公证与 Windows 发布签名；系统可能提示开发者未验证。更新前从菜单栏或托盘退出旧版，再安装新版，已有记录保留。详情见 [发布说明](docs/RELEASE.md)。

## 第一次使用，先做三件事

1. **设一条边界。** 在每日配额中设置时长、打开次数或允许使用时段，再到「连接管理」开启本机应用管理。
2. **给这次专注一个目标。** 记下今日要事，选好时长，开始专注。
3. **顺手点开时，再选一次。** 记录打开理由；选「无意识，但改邪归正」后，可确认记录并正常关闭应用，回到原来的事。

专注结束后，可以写下心得，在「历历在目」回看；每完成一次专注，镜湖收下一颗星。

## 让边界适合自己的生活

- **应用与网页配额**：每日时长、打开次数、星期规则、允许时段，以及连续使用后的休息。
- **专注与日程**：倒计时、正向计时、自定义空间和每周安排。
- **意图与回顾**：打开理由、专注心得和每日事项，按时间回看。
- **镜湖**：用星光、倒影与已确认的无意识打开，回顾自己的选择。

## 本地优先，也说明边界

无需账号，使用记录与心得保存在本机；不采集聊天内容、窗口标题或网页正文。关闭应用时先给保存工作的机会，正常关闭失败不会自动强杀。

Chrome / Edge 网页管理需单独安装随应用提供的扩展。原生应用目前按整个应用管理，不能单独隐藏客户端内部推荐流。退出留白后管理停止；托管审批和防强退尚未实现。
